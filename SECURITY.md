# Reporting security issues

Do not put credentials, private withdrawal codes, health reports or identifying information in a public issue. Use this repository's GitHub Security tab, Report a vulnerability, if private reporting is enabled. If unavailable, contact the project owner privately and request a secure channel before sharing details. Owner: enable private vulnerability reporting in repository settings. Do not send patient information by email or an issue.

Supported development line: the current main branch. There is no independent security certification or guaranteed response time. Credential exposure requires rotation; deleting text does not revoke it. See docs/ROTATE_CREDENTIALS.md and docs/LAUNCH_CHECKLIST.md.
